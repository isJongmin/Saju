# 사주풀이 노트

생년월일시를 입력하면 사주 원국, 대운, 올해운, 월운, 재물·연애·결혼·직업·건강운을 풀어주는 정적 웹사이트입니다. 서버 없이 브라우저에서 모든 계산이 이루어집니다.

## 구조

```
index.html          화면
styles.css          스타일
js/core.js          계산 엔진 (절기, 4주, 십성, 12운성, 대운, 세운/월운, 신강약)
js/interpret.js     규칙 기반 해석과 추가 질문 답변
js/app.js           입력 폼, 렌더링, 공유 링크(URL 해시)
tests/              엔진 테스트 (node:test)
```

## 계산 기준

- 절기: 태양 시황경을 Meeus 공식으로 직접 계산 (오차 약 15분 이내). 절기 경계 2시간 이내 출생이면 화면에 경고 표시
- 연주: 입춘 기준, 월주: 12절 기준
- 시주: 출생지 경도로 지방평균시 보정 (서울 약 -32분). 보정 끄기 가능
- 한국 표준시 이력: IANA tzdata `Asia/Seoul` 기준 서머타임(1948~51, 1955~60, 1987~88)과 UTC+8:30 시기(1954~61) 반영
- 자시: 기본은 23시부터 다음 날 일주, 옵션으로 야자시(당일) 선택
- 대운수: 생일에서 다음/이전 절입까지 일수 ÷ 3 반올림 (1~10)
- 나이: 세는 나이 기준
- 용신: 신강약 기반 간이 억부 용신 (조후, 격국 미반영)

## 로컬 실행

ES 모듈을 쓰므로 파일을 직접 열지 말고 로컬 서버로 엽니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 테스트

```bash
node --test tests/*.test.mjs
```
